青钢

QING / STEEL

青釉一样圆润的壳，钢尺一样精确的芯。

把 Material 3 的色调分层、胶囊形状和柔和状态层，装进一个以等宽数字、明确单位和一眼可辨的 OK/NG 为核心的工业界面。圆润负责让人愿意长时间看，精确负责让人敢于相信它。

01
分层靠明度，不靠边框。五级 surface 容器用亮度差区分层级，1px 边框只留给输入框和表格线。细边框网格是长时间注视下最先让眼睛疲劳的东西，也是“通用后台模板”感的来源。
02
两种形状，两种含义。能按的东西是胶囊（按钮、Chip、分段、导航指示器），装数据的东西是圆角矩形（卡片 16，面板 28）。形状本身告诉操作员哪里能点，不必依赖颜色或悬停。
03
数字是仪表读数，不是正文。所有测量值用等宽 tabular 数字，单位紧随其后，同列右对齐。0.79 与 3.0 的差别必须在两米外一眼读出，这是工业侧最不能让步的地方。
04
语义色独立于品牌色，NG 实色、OK 容器色。判定永远用绿 / 红 / 琥珀 / 紫四色，不与青色主色争抢注意力。NG 用实色填充、OK 用柔和容器色，因为产线上要找的是坏件，不是好件。
05
动效回答两个问题：什么变了，从哪来到哪去。导航胶囊从旧项滑到新项、分段底色滑向新选项、cycle 连接线从左向右填满、NG 从下方滑入并顶一下、缺陷描述从行内展开——每个动画都对应一次状态或位置的变化，操作员不用重新找目光落点。没有变化就没有动画：不做入场表演、不做装饰循环（唯一例外是当前阶段的呼吸点）；时长只有 120 / 240 / 400 ms 三档，超过 400 ms 就是在让操作员等。

E · 使用

接入到项目

tokens.css 只放变量，components.css 只放 qs-* 组件，qs-motion.js 只负责 CSS 做不到的位移与时序。三者都不依赖框架，可以直接接进 React / Vue / Tauri 等任意前端。

引入

<link rel="stylesheet" href="css/tokens.css">
<link rel="stylesheet" href="css/components.css">
<script src="js/qs-motion.js" defer></script>

<!-- 可选：联网时加载字体，离线自动回退到系统字体 -->
<link rel="stylesheet" media="print" onload="this.media='all'"
  href="https://fonts.googleapis.com/css2?family=IBM+Plex+Mono:wght@400;500;600&family=Noto+Sans+SC:wght@400;500;700&display=swap">

工控机通常不联网：生产环境建议把 Noto Sans SC 与 IBM Plex Mono 随应用打包（如 @fontsource/noto-sans-sc、@fontsource/ibm-plex-mono），字体栈名称保持不变即可。

主题三态

<html>                     <!-- 跟随系统，未声明时为深色 -->
<html data-theme="dark">   <!-- 强制深色 -->
<html data-theme="light">  <!-- 强制浅色 -->

QingSteel.restoreTheme('my-app-theme');
QingSteel.setTheme('light', { storageKey: 'my-app-theme' });

局部预览另一主题时给容器加 .qs-scheme-dark / .qs-scheme-light，本页 B 节的两块色板就是这样并排显示的。

交互约定

  1. 选中态写在属性上。分段按钮用 aria-pressed="true"，导航项用 aria-current="page"；不加载脚本时也能显示静态选中态。
  2. 指示器由脚本定位。QingSteel.bindSeg(el) / bindNav(el) 绑定点击并让胶囊滑动；字体加载与窗口缩放后自动重算。
  3. 数值只滚变化的字符位。QingSteel.setOdo(el, "0.81 mm")，相同值不触发，减少动态效果时直接替换。
  4. 判定切换走固定时序。QingSteel.swapVerdict(el, render, toNg)：淡出 → 换内容 → 滑入，变成 NG 时强调一次。
  5. 禁用态用两个专用角色。文字取 --on-surface-disabled（on-surface 38%），填充取 --disabled-container（12%）；描边 / 文字 / 图标按钮保持透明底，只换文字色。

密度约束

数据密度不能因圆角和留白下降。圆角 16–28 与 surface 分层会诱使页面加大内边距、拉开行距。约束：控件高 36、列表项 44、页面内边距 20、面板间距 16；420 px 宽的右栏要一屏放下 5 段测量且 NG 项展开后不出现滚动条；D 节第 1 屏在 1440×880 下无纵向滚动。胶囊按钮比直角按钮左右各多占约 6 px，密集工具栏优先用 icon 按钮和 sm 尺寸。
